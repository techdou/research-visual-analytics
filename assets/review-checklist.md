# Quick Review Checklist

- [ ] Research question is explicit.
- [ ] Core user tasks are explicit.
- [ ] Each major panel answers a task.
- [ ] Data transformations and units are visible/documented.
- [ ] Main analytical view gets enough space.
- [ ] Color has semantic meaning.
- [ ] Comparison does not rely on memory alone.
- [ ] Linked views share stable IDs/state.
- [ ] Essential information is not hover-only.
- [ ] Uncertainty/limitations are visible when material.
- [ ] Aggregate patterns can be traced to evidence if needed.
- [ ] Custom visualization has a clear advantage over a standard baseline.
- [ ] UI avoids generic business-dashboard styling unless the task truly is monitoring.
- [ ] Large data uses an appropriate rendering/query strategy.
- [ ] Research claims shown in the interface are computed, not invented.

- [ ] Selections distinguish no selection from zero matches.
- [ ] Mapping grain/cardinality and denominators are explicit.
- [ ] Pinned references survive unrelated filters; overlap is visible.
- [ ] Out-of-order results cannot overwrite the current state.
- [ ] Stored filtering is distinguished from actual model execution.
- [ ] Story/export claims match the recorded data and state.
- [ ] Critical gate failures cannot be averaged away.
- [ ] Implemented/tested/planned outcomes are separately stated.
